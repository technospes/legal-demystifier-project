# ⚖️ ParleyAlly – Legal Document Demystifier

## 📌 Overview
ParleyAlly is a **Python-based AI service** that simplifies complex legal documents into concise, user-friendly language. It combines **OCR, RAG pipelines, and Generative AI** to make legal text more accessible to everyday users.

---

## 🎯 Features
- 📝 Parse legal documents using Tesseract OCR  
- 🤖 Summarize dense legal text with Retrieval-Augmented Generation (RAG)  
- 💬 Convert jargon into human-readable explanations  
- 📂 REST API integration for scalable use  

---

## 🛠️ Tech Stack
- **Languages:** Python  
- **Libraries:** Tesseract OCR, PyTorch (learning), NumPy, Pandas  
- **AI:** RAG + Generative AI  
- **Backend:** REST APIs
